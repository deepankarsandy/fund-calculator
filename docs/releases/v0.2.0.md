# Release v0.2.0

## Features & Improvements

### 1. Dynamic Page Loading & Chunk Splitting

- Converted all application pages (`HomePage`, `WizardPage`, `FeaturesAndLogicPage`, `SipCalculatorPage`, `InvestmentCalculatorPage`, `FdCalculatorPage`, `LoanEmiCalculatorPage`, `ProfilePage`) to lazy-loaded dynamic chunks via `React.lazy` and `Suspense`.
- Configured Vite and Rollup `manualChunks` to split large third-party dependencies:
  - `vendor-charts`: Recharts and D3 dependencies are isolated so they load only on pages with charts.
  - `vendor-icons`: Lucide icons are bundled into their own chunk.
  - Page-specific chunks: Each calculator page is only fetched when navigated to.
- Initial JavaScript bundle payload reduced by over **85%** (from ~1.2 MB down to ~171 kB, ~56 kB gzipped), drastically accelerating First Contentful Paint (FCP) and initial load times.

### 2. Code Quality & Pre-Commit Formatting

- Added **Prettier** code formatter with project configuration (`.prettierrc`, `.prettierignore`).
- Configured a Git `pre-commit` hook that automatically formats staged files prior to commit.
- Added `npm run format` and `npm run format:check` scripts to `package.json`.

### 3. Semantic Versioning Enforcement

- Added Git `pre-push` hook with `scripts/verify-release.js` to enforce strict SemVer increments whenever commits are pushed to the `main` branch.
- Compares against previous versions and git tags to prevent duplicate or regressive version pushes.

### 4. Automated GitHub Releases & Tagging

- Added a `pre-push` check to verify that a release details document exists in `docs/releases/v<version>.md` before pushing to `main`.
- Added GitHub Actions workflow (`.github/workflows/release.yml`) that automatically generates the Git tag and publishes the GitHub Release with markdown release notes upon every push to `main`.
