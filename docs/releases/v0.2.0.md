# Release v0.2.0

**Release Version:** `0.2.0`  
**Previous Version:** `0.1.1`  
**Release Date:** November 2026

Release v0.2.0 is a major milestone release for the Lifetime Cost & Corpus Calculator. It introduces four standalone Indian financial calculators, a centralized User Profile system with global defaults, a complete Data Backup, Export & Import management hub, substantial UI/UX refinements, dynamic code splitting for >85% faster page load, and automated release verification tooling.

---

## What's New in v0.2.0

### 1. Four Standalone Indian Financial Calculators

In addition to the multi-step Lifetime Cost Corpus Calculator wizard, v0.2.0 adds four dedicated, standalone financial planning calculators accessible via the navigation header:

- **Systematic Investment Plan (SIP) & Systematic Withdrawal Plan (SWP) Calculator** (`/sip-calculator`):
  - **Wealth Accumulation (SIP)**: Models monthly contributions, compound growth, and annual Step-Up / Top-Up SIP contributions (percentage or fixed amount).
  - **Retirement Decumulation (SWP)**: Models monthly systematic withdrawals from an accumulated corpus, tracking capital preservation and highlighting the exact year and month of corpus depletion under rising inflation.
  - **XIRR & Extended Returns**: Computes accurate internal rate of return across step-up cashflows.
  - **Post-Budget 2024 Indian Capital Gains Taxation**: Models equity LTCG (12.5% tax above the annual ₹1.25 Lakh exemption limit) and STCG (20%), alongside debt taxation.
  - **Visual Cashflow Schedule**: Interactive Recharts graphs and full month-by-month and annual amortization tables with one-click CSV export.

- **Bank Fixed Deposit (FD) Calculator** (`/fd-calculator`):
  - **Standard Indian Banking Compounding**: Quarterly compounding interest schedule according to RBI standards.
  - **Flexible Payout Frequencies**: Supports Cumulative (reinvested interest at maturity) and Non-Cumulative payouts (Monthly, Quarterly, Half-Yearly, Annual).
  - **Senior Citizen Privileges**: Built-in toggle providing +0.50% preferential interest rates.
  - **Indian TDS Rules (Section 194A)**: Computes Tax Deducted at Source based on ₹40,000 threshold for regular depositors and ₹50,000 for senior citizens (10% with PAN, 20% without PAN), with Form 15G / 15H exemption support.

- **Investment & Multi-Asset Returns Calculator** (`/investment-calculator`):
  - **Multi-Asset Allocation**: Compounding across Equity, Debt, Gold, Real Estate, and Cash/FD asset classes.
  - **Dynamic Portfolio Rebalancing**: Simulates annual contributions, asset rebalancing, and real purchasing power adjusted for inflation.
  - **Custom Plan Cashflow Engine**: Granular year-by-year cashflow planner allowing users to model custom annual lump sums and withdrawals.

- **Loan EMI & Amortization Calculator** (`/loan-emi-calculator`):
  - **Dual Calculation Modes**: Reducing Balance EMI (standard bank loans) and Flat Rate interest models.
  - **Prepayment Simulation**: Models one-time lump sum prepayments and recurring extra monthly EMI payments, showing exact interest savings and loan tenure reduction.
  - **Indian Tax Relief**: Automatically computes eligible tax deductions under Section 24(b) (Home loan interest deduction up to ₹2,00,000) and Section 80C (Principal repayment deduction up to ₹1,50,000).
  - **Detailed Amortization Tables**: Month-by-month and year-by-year principal vs. interest breakdown.

### 2. Centralized User Profile & Global Defaults

- **Unified Financial Identity** (`/profile` & modal drawer):
  - Centralizes personal demographics: Date of Birth (with dynamic age calculation), Current Age, Target Retirement Age, and Planning Life Expectancy.
  - Geographic Cost of Living: Rural (0.6×), Small Town / Tier 3 (1.0×), City / Tier 2 (1.6×), or Tier 1 Metro (2.5×).
  - Financial baselines: Net monthly income, expected career increment rate, existing investable corpus, baseline equity/debt returns, and tax slab / regime.
  - Calibrated Sector-Specific Inflation rates: Distinct inflation benchmarks for Healthcare (7%), Family & Education (7%), Housing (5%), Technology (3%), and general expenses.
- **Global Synchronization**:
  - Updating the User Profile can automatically propagate and pre-populate defaults across the Lifetime Corpus Calculator wizard and all standalone calculators.
  - Real-time in-browser reactive event bus (`fundcalc_user_profile_updated`) updates all active components without page refreshes.

---

### 3. Data Backup, Export & Import Management

- **Client-Side Data Portability Hub** (`/export-import`):
  - **Complete Backup**: One-click download of a timestamped `.json` file containing all application data across 8 modular sections: Profile, Retirement Wizard, SIP/SWP, Investments, Fixed Deposits, Loan EMI, Settings, and Theme.
  - **Granular Export & Import**: Selectively export or restore individual modules without affecting other calculator data.
  - **Schema Validation & Conflict Previews**: Inspects uploaded backups, confirms compatibility, and presents live summaries before applying changes.
  - **Automatic Safety Snapshot**: Automatically creates a rollback recovery backup in `localStorage` prior to applying any import, allowing instant one-click restoration in case of accidental overwrites.
  - **Zero Cloud Dependence**: 100% client-side execution; financial data is never sent to external servers.

### 4. UI/UX Refinements

- **Calculators Dropdown Menu**: High-visibility header navigation dropdown (`CalculatorsDropdown.tsx`) allowing instant switching between the Lifetime Corpus Wizard, SIP/SWP, FD, Investment, and Loan EMI calculators.
- **Shortfall Management Remedies**: Dynamic `ShortfallManagementCard.tsx` on the retirement results step that suggests actionable remedies when projected funds face a deficit (adjust retirement age, alter savings rate, reduce post-retirement discretionary expenses, or adopt step-up investing).
- **Refined Wizard Stepper**: Clean, mobile-friendly `WizardStepper.tsx` with clear milestone indicators, step numbers, and direct navigation jumps.
- **Enhanced Form Controls**: Currency adornments formatted with Indian Rupee (₹) numbering system (Lakhs and Crores), percentage badges with clean spacing, and real-time input validation warnings.
- **Responsive Data Visualizations**: High-contrast Recharts charts with theme-adaptive tooltips, legends, and mobile-optimized table layouts.

---

### 5. Performance & Architecture Optimizations

- **Dynamic Code Splitting**:
  - Converted all page routes (`HomePage`, `WizardPage`, `FeaturesAndLogicPage`, `SipCalculatorPage`, `InvestmentCalculatorPage`, `FdCalculatorPage`, `LoanEmiCalculatorPage`, `ProfilePage`, `ExportImportPage`) to lazy-loaded chunks using `React.lazy` and `Suspense`.
  - Configured Vite Rollup `manualChunks` to split heavy vendor dependencies:
    - `vendor-charts`: Recharts and D3 dependencies load strictly on pages displaying charts.
    - `vendor-icons`: Lucide icon bundle is isolated.
    - Page-specific chunks load on-demand during navigation.
  - Initial JS bundle reduced by **over 85%** (from ~1.2 MB down to ~171 kB, ~56 kB gzipped), drastically improving First Contentful Paint (FCP).

---

### 6. Developer Experience & Release Automation

- **Pre-Commit Code Quality**: Configured Prettier with Git `pre-commit` hook for automated code formatting across staged files.
- **SemVer Pre-Push Enforcement**: Added `scripts/verify-release.js` run via `.githooks/pre-push` to guarantee that every push to `main` strictly increments SemVer and contains an associated release notes document.
- **Automated GitHub Releases**: GitHub Actions workflow (`.github/workflows/release.yml`) automatically tags the commit and publishes the release on GitHub with release notes.
