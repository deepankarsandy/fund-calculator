# Release v0.3.1

**Release Version:** `0.3.1`  
**Previous Version:** `0.3.0`  
**Release Date:** November 2026

Release v0.3.1 is a minor bugfix and UX enhancement release addressing Date of Birth (DOB) input, calendar picker ergonomics, mobile browser compatibility, and demographic layout improvements in the Financial Profile manager (`ProfilePage.tsx`).

---

## What's Changed in v0.3.1

### 1. Native HTML Date Picker with $\pm 100$-Year Bounding (`ProfilePage.tsx`)

- **Native HTML Date Picker Integration**:
  - Replaced the legacy plain text input with a native HTML date picker (`<input type="date" lang="en-US" ... />`).
  - Guarantees seamless cross-device mobile compatibility on both **Android** (opens native Material DatePicker dialog) and **iPhone** (opens native iOS wheel/sheet picker).
  - Configured `[color-scheme:light] dark:[color-scheme:dark]` for native browser calendar popups in dark mode.
  - Added programmatic `e.currentTarget.showPicker?.()` invocation on click so desktop users can click anywhere across the field to launch the native calendar.
- **$\pm 100$-Year Calendar Bounds**:
  - Applied dynamic `min` and `max` constraints calculated from the current year (`min={currentYear - 100}` to `max={currentYear + 100}`) to clamp the default calendar picker within a safe 100-year window.

---

### 2. Real-Time Computed Age in Info Text Area

- **Dynamic Age Calculation Feedback**:
  - The informational text area located immediately below the DOB field dynamically computes and displays the user's exact age in real-time when a valid DOB is selected.
  - Accompanied by a success badge (`CheckCircle2`) and explicit date format confirmation in `MM-DD-YYYY` (e.g., `Age: 30 years old (11-21-1996)`).
  - Falls back gracefully to instructional text (`Select your date of birth (MM-DD-YYYY) to auto-compute your age.`) when cleared or invalid.

---

### 3. Lifestyle Baseline Dropdown (Replacing Age Input)

- **Demographic Layout Reorganization**:
  - In place of the manual numeric age input, the **Lifestyle Baseline** selector is now rendered as a clean, standardized dropdown (`<select>` with custom `ChevronDown` indicator).
  - Options include:
    - **Bare Minimum**: Survival essentials only (~50% metro benchmark)
    - **Comfortable**: Leisure, outings & buffer (default benchmark)
    - **Luxury**: Premium lifestyle & higher contingency buffer
    - **Custom**: Manually itemized expense configuration
  - Removed the redundant 4-card lifestyle selector grid from below the retirement horizon section, eliminating duplicate controls and keeping the Personal & Horizon tab compact and symmetrical.

---

### 4. Domain Model Date Normalization Enhancements (`userProfile.ts`)

- **`MM-DD-YYYY` Format Support**:
  - Enhanced `isValidDob`, `calculateAgeFromDob`, and `normalizeDobToDdMmYyyy` to intelligently disambiguate and support `MM-DD-YYYY` strings alongside standard `YYYY-MM-DD` and `DD/MM/YYYY`.
- **Date Conversion Utilities**:
  - Added `parseDobToIso(dob: string): string` to convert any supported DOB format into standard `YYYY-MM-DD` ISO strings for native HTML date picker elements.
  - Added `formatDobToMmDdYyyy(dob: string): string` to format any supported DOB string into human-readable `MM-DD-YYYY`.
- **Unit Test Coverage**:
  - Added test cases in `src/lib/__tests__/userProfileStorage.test.ts` validating `MM-DD-YYYY` validation, ISO parsing, and string formatting.
