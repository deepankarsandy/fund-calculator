# Financial & Macroeconomic Assumptions

Step 5 allows users to define key economic drivers: inflation rates, investment return expectations, and scenario presets.

---

## Overview

A lifetime financial plan spanning 30 to 60 years is highly sensitive to the spread between inflation ($g$) and investment return ($r$). The calculator provides realistic default boundaries, differential healthcare inflation modeling, and one-click market presets.

---

## Key Features

### 1. Differential Inflation Modeling
- **General Global Inflation Rate ($g$)**: Applied to standard household living costs (default: 6.0%/year).
- **Healthcare Inflation Rate**: Medical costs historically inflate faster than consumer goods. A separate medical inflation rate (default: 8.0%/year) can be applied to Category D (Healthcare).

### 2. Investment Return Expectations ($r$)
- **Nominal Annual Return**: Expected gross portfolio return across asset classes (default: 10.0%/year).
- **Blended Portfolio Estimation**: Supports specifying expected returns across equity, debt/fixed income, gold, and real estate, or using a single blended portfolio return.
- **Return Basis**: Supports nominal returns or real (net of inflation) returns.

### 3. Pre-Configured Market Scenario Presets
To stress-test the plan without manual re-typing, three market scenarios are modeled simultaneously:
1. **Optimistic**:
   - Inflation: 5.0%
   - Investment Return: 12.0%
   - High equity outperformance, low inflation drag.
2. **Base (Realistic Default)**:
   - Inflation: 6.0%
   - Investment Return: 10.0%
   - Balanced long-term historical Indian equity/debt return assumption.
3. **Conservative**:
   - Inflation: 7.5%
   - Investment Return: 8.5%
   - High inflationary pressure with moderate debt-heavy portfolio returns.

### 4. Interactive Scenario Selector
- On the final results page, users can toggle between Optimistic, Base, and Conservative scenarios with a single click to inspect portfolio curves under varying market cycles.
