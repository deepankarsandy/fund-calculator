# Profile & Location-Calibrated Defaults

The **Profile** step establishes the user's demographic baseline, planning longevity horizon, and geographic cost-of-living context across India.

---

## Overview

Living costs vary drastically between rural areas, small towns, tier-2 cities, and tier-1 metros. Rather than forcing users to guess standard living costs from scratch, the calculator uses location tiers and age parameters to generate realistic default baselines.

---

## Key Features

### 1. Indian Cost-of-Living Area Tiers

Users can select from four calibrated geographic tiers:

- **Village / Rural (0.6× base multiplier)**: Modest housing, local/homegrown food, lower utilities, and minimal municipal overheads.
- **Small Town / Tier 3 (1.0× baseline)**: Moderate living costs calibrated to product guide benchmarks (e.g. small-town Odisha baseline).
- **City / Tier 2 (1.6× multiplier)**: State capitals and industrial hubs (e.g., Bhubaneswar, Jaipur, Chandigarh, Kochi, Pune).
- **Tier 1 Metro (2.5× multiplier)**: Major metropolitan areas with premium real estate and services (Mumbai, Bengaluru, Delhi NCR, Hyderabad, Chennai).

### 2. Longevity Risk & Planning Horizon

- **Current Age**: Baseline starting age ($t = 0$). Default: 30.
- **Target Planning Age**: The age up to which the corpus must sustain living costs safely.
- **Longevity Buffer Reminder**: Built-in prompts encourage testing out to age 85, 90, or 100 rather than assuming traditional life expectancy (age 70), protecting users against outliving their capital.

### 3. Lifestyle Baseline Preset

- Choose an initial lifestyle tier: **Bare Minimum**, **Comfortable**, or **Luxury / Aspirational**.
- This choice automatically toggles discretionary expenses and adjusts category defaults.

### 4. Automatic Recalibration

- Changing the geographic tier or current age automatically recalculates default expense allocations for all 11 categories without breaking existing customized values.
